# Glossary (Turkish identifiers → English)

The native code keeps the original Turkish names. Common terms:

| Turkish | English |
|---|---|
| telsiz | walkie-talkie / radio |
| afet | disaster |
| motor (`TelsizMotoru`) | engine |
| kanal, kanalAdi | channel, channel name |
| ad, maskeli ad | name, masked name |
| kisi (kişi kodu) | person code (random per device) |
| mesaj, metin, ses | message, text, voice/audio |
| kayit, kayitBaslat / kayitBitir | recording, start / stop recording |
| cal, calici | play, player |
| gonder, gonderKime, al | send, send to, receive |
| kablo | wire (serialized payload) |
| cerceve, cercevele, birlestirici | frame, to frame, reassembler |
| sifre, sifrele, coz | encryption, encrypt, decrypt |
| atlama | hop (relay count) |
| omur | lifetime |
| bagli, baglanti | connected, connection |
| cevre (birimi), merkez | (BLE) peripheral, central |
| tasima, ek taşıma | transport, additional transport |
| yakin | nearby |
| durum, durumOzeti | status, status summary |
| guvende / toplanma / yardim | safe / at assembly point / need help |
| yardim (çağrısı), ihtiyac, kisiSayisi, not | help (call), need, number of people, note |
| enkaz, yarali, su-gida, barinma, ilac, diger | trapped under debris, injured, water-food, shelter, medicine, other |
| yardimaGidiyorum | "I'm coming to help" |
| davet, davetYaniti, kabul | invitation, invitation reply, accept |
| varlik | presence ("I'm here") |
| duyuru | announcement |
| bekleyenler, yuklendi, disaridan | pending (uploads), uploaded, from outside (server) |
| konum, enlem, boylam | location, latitude, longitude |
| izin | permission |
| bildirim | notification |
| arka plan, ön plan | background, foreground |
| pil | battery |
| ekran | screen |
| test paneli | debug panel |
| metinler (`TelsizMetin`) | UI strings |
